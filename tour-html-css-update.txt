=== 1. In <head>, add the Pannellum files (before your own <style>) ===

<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/pannellum/2.5.6/pannellum.css">
<script src="https://cdnjs.cloudflare.com/ajax/libs/pannellum/2.5.6/pannellum.js"></script>


=== 2. In the tour pop-up HTML, add one line right after the <img id="tourImg"> line ===

<div id="tourPano"></div>

(The pop-up should now contain: close button, <img id="tourImg">, <div id="tourPano">, prev/next buttons, caption.)


=== 3. Add to your CSS ===

#tourPano {
  display: none;
  position: absolute;
  inset: 0;
  width: 100%;
  height: 100%;
}
.tour-nav, .tour-caption { z-index: 5; }
.tour-close { z-index: 6; }
.tour-caption { pointer-events: none; }   /* lets you drag the 360 view through the caption area */
